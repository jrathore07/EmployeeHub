# 🚀 EmployeeHub - Employee Management System

A Full Stack Employee Management System built using **Spring Boot**, **Angular**, and **MySQL**.

This project was created as my **first Angular Full Stack application** to understand how a modern frontend communicates with a Spring Boot REST API. While building it, I explored frontend-backend integration, RESTful APIs, routing, forms, HTTP communication, and CRUD operations.

It was a challenging journey with many debugging sessions, but every issue helped me learn something new. This project represents my practical learning experience in Full Stack Development.

---

# 📌 Project Objective

The goal of this project was to learn:

- Building REST APIs using Spring Boot
- Creating a modern frontend using Angular
- Connecting Angular with Spring Boot
- Performing complete CRUD operations
- Working with MySQL Database

- Learning real-world project structure

# 🔗 REST APIs

| Method | Endpoint | Description |
|----------|----------------------------|----------------|
| GET | /api/v1/employees | Get All Employees |
| GET | /api/v1/employees/{id} | Get Employee By ID |
| POST | /api/v1/employees | Create Employee |
| PUT | /api/v1/employees/{id} | Update Employee |
| DELETE | /api/v1/employees/{id} | Delete Employee |

# ▶ How to Run

## Backend

Open the project in **IntelliJ IDEA**

Run:

```
FirstAngularApplication
```

Backend runs on

```
http://localhost:8080
```

---

## Frontend

Open

```
angular-frontend
```

using **Visual Studio Code**

Install packages

```
npm install
```

Run

```
ng serve
```

Frontend runs on

```
http://localhost:4200
```
